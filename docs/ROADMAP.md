# 首版限制与后续工作

当前提交完成了核心可运行闭环，但以下计划项仍需要发行版集成环境才能安全交付，不能仅通过 Windows 开发机模拟：

- certbot/acme.sh 续期状态面板和到期告警；绑定、失败回滚及 IP 入口恢复已经实现，但仍需发行版 VM 验证。
- Docker 日志流、镜像构建上传及 Compose 实时流式日志 UI；容器交互终端和对象任务接口已经实现。
- 更多告警渠道与完整静默日历；当前已支持阈值持续时间、重复间隔、恢复通知、SMTP 和 Webhook。
- AnPanel 自更新签名、二进制回滚和配置迁移 UI。
- 在 Ubuntu、Debian、CentOS、Rocky、AlmaLinux 的 amd64/arm64 VM 矩阵中执行破坏性安装/回滚测试。

这些功能不应在缺少真实 Linux VM 和发布签名密钥时伪装成“已验证”。
