# 路线图与验收状态

本文区分“代码已实现”和“已在正式支持环境验证”。CI 通过代表代码、前端和交叉编译检查成功，不等于发行版安装与破坏性回滚测试已经完成。

## 当前里程碑：首个可验证版本

已进入代码主线：

- [x] Go 单二进制与内嵌 React 管理端
- [x] 普通用户 Web 服务与 root agent 权限隔离
- [x] SQLite WAL、认证、TOTP、CSRF、限速、会话与审计
- [x] 主机实时指标、分层历史和基础告警
- [x] Docker 容器及对象管理、Compose 受限任务和容器终端
- [x] Nginx/Apache 发现、配置验证、原子写入和失败回滚
- [x] certbot/acme.sh 域名入口、失败回滚和访问恢复
- [x] apt/yum/dnf 地区源选择、备份、缓存验证和回滚
- [x] amd64/arm64 构建、校验和、可选 Ed25519 签名与 Release Actions

## 后续功能

### P1：补齐管理闭环

- [x] 添加站点向导（静态 / 反代）与 SSL 证书列表续期
- [x] 面板正式版自更新、文件管理、Crontab、应用市场 Docker 一键部署绑站
- [x] 伪静态模板、软件互斥安装、编译安装默认、PHP 多版本、Certbot/acme.sh 安装
- 证书到期告警和续期失败诊断
- Docker 日志实时流、镜像构建上传及 Compose 实时任务日志
- 数据库迁移与二进制自动回滚
- 站点冲突、链式代理和重复域名的可视化诊断

### P2：运营与可观测性

- 更细的磁盘 I/O、网络和 Docker 资源历史
- 告警静默日历、通知模板和投递历史
- 配置备份浏览、差异对比与手动恢复
- systemd 任务日志和安装诊断包导出

### 暂不纳入首版

- 多服务器集群与 RBAC
- 数据库/PHP 应用商店
- 完整文件管理器或宿主机 Web 终端
- 防火墙和云安全组管理

## 发布验收标准

候选版本只有在以下链路于目标 VM 中可重复通过后才能标记为稳定版：一行命令安装、首次强制改密、现有组件识别、历史指标、全部本机 Docker 清单、Nginx/Apache 站点导入与安全修改，以及每一种配置失败场景下的自动回滚和访问恢复。
